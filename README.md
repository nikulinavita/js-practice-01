## Ответы на вопросы

### 1. Почему мы используем `textContent` вместо `innerHTML` для вывода простого текста?
**Ответ:**  
Мы используем `textContent`, когда нужно вывести только текст, а не HTML.  
Введённый текст воспринимается как простой текст, а не как HTML-код.  
Это предотвращает выполнение нежелательного HTML или скриптов и защищает от XSS-атак.

### 2. В чем разница между `let` и `const`? Когда какую переменную использовать?
**Ответ:**  
- `let` — создаёт переменную, значение которой можно изменять после объявления  
- `const` — создаёт переменную, значение которой нельзя изменить или переопределить  

**Когда использовать:**  
- `let` — если значение переменной будет меняться в ходе работы программы  
- `const` — если значение должно оставаться постоянным; рекомендуется использовать по умолчанию для безопасности и предсказуемости кода  

### 3. Почему `addEventListener` считается более правильным подходом, чем inline-события в HTML?
**Ответ:**  
`addEventListener` предпочтительнее, потому что:  
- **Разделение HTML и JavaScript** — код событий хранится в JS-файле, HTML остаётся чистым  
- **Поддержка нескольких обработчиков** — на один элемент можно повесить несколько слушателей одного события  
- **Больше контроля** — можно удалять обработчики через `removeEventListener`, управлять порядком выполнения, использовать опции `capture` и `once`  
- **Безопасность и читаемость** — легче поддерживать код, меньше риск ошибок и случайного выполнения кода
